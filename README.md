## 🚀 Featured projects

### 🏋️ GymDesk — Gym Management System
**[🔗 Live](https://gymdesk-crm-353e0b95ec17.herokuapp.com/)** · *private source*

A CRM for gyms: membership sales, partial payments and debt tracking, a Telegram bot for members, and an owner dashboard. The reception screen is built so an admin with little computer experience can serve a member in **3–5 seconds**.

- **Money you can trust:** append-only payment ledger with reversal entries; debt is calculated, never typed; complimentary memberships are blocked from revenue reports by database constraints
- **Security:** JWT access token in memory + rotating refresh token in an HttpOnly cookie, role-based access (Owner / Admin), idempotent payment endpoints
- **Automation:** Telegram bot via secured webhook, scheduled expiry and debt reminders with ShedLock
- **Stack:** Java 21 · Spring Boot 3 · PostgreSQL · Flyway · React + TypeScript · TanStack Query · Docker · Heroku
